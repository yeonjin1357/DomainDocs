<Situation>
  오후 2시에 주문 API를 배포한 뒤 p99 응답시간이 400ms에서 900ms로 올랐어요. 에러는 늘지 않았어요.

  배포 뒤에 느려졌다고 꼭 새 코드 탓은 아니에요. 같은 시각에 다른 일이 겹쳤을 수도, 막 뜬 서버라 잠깐 느린 것일 수도 있어요. 새 버전만 느린지, 잠깐인지를 먼저 가려요.

## 1. 느려진 시각과 배포 시각을 맞춰 보세요

응답시간 그래프에 배포 시각을 표시해 두면 한눈에 겹쳐 보여요. Grafana에서는 이런 표시를 주석(annotation)이라고 해요.

롤링 업데이트는 인스턴스를 조금씩 바꿔 끼워요. 쿠버네티스 Deployment의 기본값은 원하는 수의 25%까지 더 띄우고 25%까지 비워 두는 방식이에요. 그래서 배포 중에는 옛 버전과 새 버전이 섞여 있고, 그래프도 서서히 바뀌어요.

느려진 시각이 배포보다 앞섰다면 배포 탓이 아니에요. 같은 시각에 트래픽, DB, 바깥 API에 무슨 일이 있었는지 <Term slug="apm/slow-response">응답이 느려졌을 때</Term>의 순서로 봐요.

## 2. 버전별로 나눠 보세요

버전별로 나누려면 지표와 트레이스에 버전이 붙어 있어야 해요. OpenTelemetry는 이 값을 `service.version`이라는 리소스 속성으로 정해 둬요. 배포 도구가 이 값을 채우게 해 두면, 화면에서 버전으로 나눠 볼 수 있어요.

배포가 이미 끝나 옛 버전이 없다면, 배포 전 같은 요일·시간대와 견줘요.

## 3. 잠깐 느렸다면 웜업이에요

막 뜬 서버는 몇 분 동안 느릴 수 있어요. 대표적인 이유는 둘이에요.

- **JIT 컴파일**: 자바는 처음엔 코드를 가볍게 실행하며 정보를 모으고, 자주 쓰는 메서드를 최적화된 기계어로 컴파일해요. 컴파일이 끝나기 전까지는 같은 요청도 더 느려요.
- **빈 캐시**: 새로 뜬 인스턴스의 메모리 캐시는 비어 있어서, 처음 요청들은 DB까지 가요. <Term slug="apm/cache">캐시와 적중률</Term>에서 다뤄요.

<Figure caption="같은 요청 처리 코드를 자바 17에서 1,000건씩 돌려 잰 요청당 평균 시간이에요. 막 뜬 JVM의 첫 1,000건이 컴파일이 끝난 뒤보다 3~5배 느렸어요. JIT를 끄고 인터프리터로만 돌리면 내내 615µs였어요.">

이런 느림은 몇 분 안에 스스로 돌아와요. 배포 때마다 반복된다면, 트래픽을 받기 전에 데우는 요청을 보내거나 준비 완료(readiness) 신호를 늦춰요.

## 4. 계속 느리다면 무엇이 달라졌는지 견주세요

30분이 지나도 새 버전만 느리다면 코드나 설정이 바뀐 거예요. 같은 요청의 트레이스를 옛 버전과 새 버전에서 하나씩 골라 나란히 봐요.

- **새로 생긴 구간**: 새 버전이 바깥 API를 하나 더 부르나 봐요.
- **늘어난 SQL 수**: 같은 SQL이 줄지어 있다면 <Term slug="apm/n-plus-one">N+1</Term>이에요.
- **바뀐 설정**: 커넥션 풀 크기, 타임아웃, 스레드 수 같은 값이 바뀌었나 봐요.
- **바뀐 라이브러리**: 의존성 버전이 올라갔나 봐요.

트레이스에서 차이가 안 보이면 CPU를 어디에 쓰는지 견줘요. 버전별 불꽃 그래프를 비교하는 법은 <Term slug="apm/continuous-profiling">지속 프로파일링</Term>에 있어요.

## 5. 되돌릴지 먼저 정하세요

원인을 다 찾을 때까지 기다리지 않아도 돼요. 사용자에게 영향이 크면 먼저 되돌리고, 옛 버전으로 돌아온 뒤에 원인을 찾아요.

Google SRE Workbook은 새 버전을 일부에만 먼저 내보내 견주는 <Term term="apm/canary">카나리</Term>를 권해요. 새 버전이 기존 버전보다 눈에 띄게 나쁘면 배포를 멈추고 되돌리라고 해요.

카나리는 영향을 줄여 줘요. 문서의 예에서 요청의 20%를 실패시키는 버전을 트래픽 5%에만 내보내면, 전체 실패율은 1%에 그쳐요. 얼마나 나빠야 되돌릴지는 <Term slug="foundations/slo-and-error-budget">SLO와 에러 예산</Term>으로 미리 정해 둬요.
