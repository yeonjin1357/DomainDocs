  </Point>

## 커밋과 롤백

트랜잭션은 <Term term="database/commit">커밋</Term>이나 <Term term="database/rollback">롤백</Term>으로 끝나요.

<Figure caption="커밋하면 바뀐 내용이 확정되고 다른 세션에 보여요. 롤백하면 처음부터 없던 일이 돼요.">

기본 설정에서는 트랜잭션이 열려 있는 동안 바꾼 내용이 다른 세션에 보이지 않아요. 커밋하는 순간 모든 변경이 한꺼번에 보여요. 그래서 다른 세션은 앨리스 잔액만 줄어든 중간 상태를 보지 못해요.

DB가 커밋이 끝났다고 알리면, 그 직후 장애가 나도 변경은 남아요. 커밋 때 바뀐 내용을 <Term term="database/wal">로그</Term>에 확실히 적어 두기 때문이에요. 자세한 흐름은 <Term slug="database/memory-and-disk">메모리와 디스크</Term>에 있어요.

## 따로 묶지 않으면 문장마다 커밋해요

트랜잭션을 직접 열지 않으면, DB나 드라이버가 SQL 한 문장마다 트랜잭션을 열고 커밋해요. 이것을 <Term term="database/autocommit">자동 커밋</Term>이라고 불러요.

| 어디서 | 기본 동작 |
| --- | --- |
| PostgreSQL | `BEGIN`이 없으면 문장마다 커밋 |
| MySQL | 새 연결은 자동 커밋으로 시작 |
| Oracle | 첫 SQL에서 트랜잭션이 시작돼 `COMMIT`·`ROLLBACK`까지 열려 있음 |
| JDBC 연결 | 기본으로 자동 커밋 |

여러 SQL을 한 묶음으로 처리해야 한다면, 자동 커밋에 맡기지 말고 트랜잭션을 직접 열어요. 자동 커밋을 껐다면 반대로 커밋을 빠뜨리지 않아야 해요.

DB 화면의 TPS(초당 트랜잭션 수)는 보통 커밋과 롤백을 더한 값이에요. PostgreSQL은 데이터베이스마다 커밋 수(`xact_commit`)와 롤백 수(`xact_rollback`)를 세어요.

롤백 비율이 갑자기 오르면 앱에서 에러가 늘었다는 신호일 수 있어요. 오래 열린 트랜잭션도 함께 봐요. PostgreSQL은 세션마다 트랜잭션을 연 시각(`xact_start`)을 보여 줘요.

오래 열린 트랜잭션은 잠금을 쥔 채 다른 세션을 막기 쉬워요. 막힌 사슬을 찾는 법은 <Term slug="database/locks-and-blocking">잠금과 블로킹</Term>에 있어요.

<Deeper>
  ### ACID

  트랜잭션이 지키는 네 가지 성질을 앞 글자를 따서 ACID라고 불러요. 원자성(Atomicity), 일관성(Consistency), 격리성(Isolation), 지속성(Durability)이에요.

  이 글의 "전부 아니면 전무"가 원자성, "커밋 전 변경은 남에게 안 보여요"가 격리성, "장애가 나도 남아요"가 지속성이에요.

  ### 격리 수준

  격리성에는 여러 단계(격리 수준)가 있어요. 기본값은 PostgreSQL과 SQL Server가 READ COMMITTED, MySQL InnoDB가 REPEATABLE READ예요. 이 기본값에서는 커밋 전 변경을 읽지 않아요.

  가장 느슨한 READ UNCOMMITTED에서는 커밋 전 변경까지 읽어요. 이를 dirty read라고 하고, SQL Server의 `NOLOCK` 힌트도 같은 효과예요. PostgreSQL은 READ UNCOMMITTED를 요청해도 READ COMMITTED처럼 동작해요.

  ### Oracle에서 트랜잭션이 끝나는 때

  Oracle의 트랜잭션은 `COMMIT`이나 `ROLLBACK` 말고도 끝나요. `CREATE`, `DROP`, `ALTER` 같은 DDL을 실행하면 트랜잭션이 끝나요.

  도구를 정상적으로 끝내면 대부분 열린 트랜잭션을 커밋해요. 클라이언트가 비정상으로 끊기면 롤백해요.

  ### MySQL의 자동 커밋 끄기

  MySQL에서 `SET autocommit = 0`으로 자동 커밋을 끄면, 그 세션에는 늘 트랜잭션이 열려 있어요. `COMMIT`이나 `ROLLBACK`으로 끝내면 곧바로 새 트랜잭션이 시작돼요.
</Deeper>
