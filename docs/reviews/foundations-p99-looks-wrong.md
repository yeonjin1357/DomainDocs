# 사실 검토: p99가 이상하게 나올 때

- 글: src/content/docs/foundations/p99-looks-wrong.mdx
- 검토일: 2026-10-14
- 결과: 수정 필요 3건 / 확인 29건
- 검증: 원문은 curl로 받은 문서 HTML과 v3.15.0 태그의 소스·문서(raw.githubusercontent.com)로 읽었어요. 질의는 컨트롤러가 받아 둔 promtool 3.15.0(revision 5241a27f)으로 `check rules`(글의 코드 블록 5개를 글자 그대로), `test rules`(1분 간격 합성 데이터, 기대값 -1로 실제 값을 읽음), `tsdb create-blocks-from openmetrics`·`tsdb dump`(수집 때 `le` 정규화 확인)를 돌렸어요. 숫자는 node로 다시 계산했어요. 서버는 띄우지 않았어요. 그래서 `warnings`·`infos` 주석은 실행으로 보지 못했고 소스로만 확인했어요(promtool `test rules`는 주석을 보여 주지 않아요).
- 문서와 소스가 다른 곳: `le`가 없는 샘플을 functions 문서는 "silently ignored"라고 하지만, v3.15.0 소스는 경고를 달고 건너뛰어요. 실제 동작은 소스가 정하므로 글(확인 2)은 소스대로 쓴 지금이 맞아요. 아래 표 "확인 2" 행에 근거를 적었어요.
