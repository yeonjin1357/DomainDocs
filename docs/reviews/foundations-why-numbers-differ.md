# 사실 검토: 같은 지표가 화면마다 다르게 보이는 이유

- 글: src/content/docs/foundations/why-numbers-differ.mdx
- 검토일: 2026-10-13
- 결과: 수정 필요 2건 / 확인 32건

계산은 node로 다시 했어요. Grafana 간격은 프런트엔드 `PanelQueryRunner` → `rangeUtil.calculateInterval`(하한: 패널 Min interval, 없으면 데이터 소스 Scrape interval)과 백엔드 `InterpolateVariables` → `calculateRateInterval` 순서로 옮겼어요. rate는 Prometheus `extrapolatedRate`(10초 수집)로 흉내 냈어요. p99는 nearest-rank(정렬 뒤 ⌈p×n/100⌉번째)로 셌어요. 개념 글 세 편(percentiles, counters-and-rate, aggregation-and-downsampling)과 어긋나는 곳은 찾지 못했어요.
